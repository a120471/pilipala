准备编译环境

去https://docs.flutter.dev/install/archive下载并安装flutter 3.19.6
    - 关闭不需要的linux-desktop开发环境
        - flutter config --no-enable-linux-desktop
    - 运行 flutter doctor -v 检查环境的配置情况，根据提示进行补充安装

安装android sdk
    - 下载cmdline-tools
        - https://dl.google.com/android/repository/commandlinetools-linux-15859902_latest.zip
        - 设置ANDROID_HOME环境变量
    - 安装platform-tools
        - android sdk install "platform-tools" "platforms;android-36" "build-tools;28.0.3"

安装jdk17
    - sudo apt install openjdk-17-jdk


拉取 Flutter 依赖包
    - flutter pub get

编译
    - flutter build apk --target-platform android-arm64 --split-per-abi --debug
    - 编译结果
        - build/app/outputs/flutter-apk/app-arm64-v8a-debug.apk
